VacuGo landing page - conversion prototype.

Що оновлено:
- сильніший перший екран з офером 699 грн замість 999 грн;
- блок "До / Після";
- таймер акції до кінця поточного дня;
- форма заявки під Telegram;
- статуси форми: відправка, успіх, помилка;
- демо-відгуки залишені як макетні.

Як підключити Telegram напряму для локального тесту:
1. Створіть бота через @BotFather і отримайте BOT_TOKEN.
2. Дізнайтеся CHAT_ID чату або каналу, куди мають падати заявки.
3. У файлі script.js заповніть:

const TELEGRAM_CONFIG = {
  botToken: "BOT_TOKEN",
  chatId: "CHAT_ID",
  proxyUrl: ""
};

4. Відкрийте index.html, заповніть форму і перевірте, що заявка приходить у Telegram.

Рекомендований варіант для реклами:
Не залишайте BOT_TOKEN у відкритому client-side JS на реальному трафіку. Краще зробити serverless/proxy endpoint, який приймає заявку з сайту і вже з сервера відправляє її в Telegram. Тоді в script.js заповніть тільки proxyUrl, а botToken і chatId зберігайте на сервері.

Поточна серверна схема вже підготовлена:
- форма надсилає заявку на /api/order;
- файл api/order.js відправляє заявку в Telegram;
- TELEGRAM_BOT_TOKEN і TELEGRAM_CHAT_ID потрібно додати в Environment Variables на Vercel.

Деплой на Vercel з пробним періодом:
1. Зареєструйтеся на https://vercel.com.
2. Для комерційного лендінгу краще взяти Pro trial, якщо він доступний у вашому акаунті. Для тесту можна розгорнути проєкт і перевірити технічно.
3. Створіть новий проєкт.
4. Завантажте папку сайту або підключіть GitHub-репозиторій з цими файлами.
5. У Project Settings -> Environment Variables додайте:

TELEGRAM_BOT_TOKEN=токен_бота
TELEGRAM_CHAT_ID=chat_id

6. Redeploy проєкт після додавання змінних.
7. Відкрийте production URL, заповніть форму ПІБ + телефон і перевірте заявку в Telegram.

Важливо:
Якщо токен бота вже був у script.js на локальному етапі, краще перевипустити його в @BotFather через /revoke і новий токен додати тільки у Vercel Environment Variables.

Перед запуском реклами:
- замініть демонстраційні відгуки на реальні;
- перевірте актуальну комплектацію партії;
- вкажіть реальні умови доставки, оплати та гарантії;
- протестуйте форму з телефону й десктопу.
